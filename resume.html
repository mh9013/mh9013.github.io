Analysis Bot — RAG 문서 분석 챗봇

2026.03 — 2026.04
개인 프로젝트 · 풀스택 & 인프라 책임
문제
사내 규정·계약서 같은 문서를 LLM에 질의할 때 단일 검색 방식만으로는 의미와 고유 표현(회사명·법적 용어)을 동시에 잡기 어렵고, OpenAI 같은 단일 프로바이더에 의존하면 API 키 누락·rate limit·장애 상황에서 서비스가 그대로 멈춥니다. 여기에 수동 배포와 롤백까지 더해지면, 장애 발생 후 복구까지의 공백이 길어집니다.
해결
하이브리드 검색 — pgvector 0.7 + tsvector 0.3 벡터·키워드 검색 결과를 가중합해 의미·표현 매칭을 동시에 확보했습니다. 가중치는 자체 샘플 문서로 반복 튜닝해 결정했습니다.
멀티 프로바이더 자동 라우팅 — OpenAI → Claude → Gemini 단일 프로바이더 의존을 제거하고, 로컬에서 키 제거·응답 지연 시나리오를 시뮬레이션해 전환 동작을 검증했습니다.
Kubernetes + ArgoCD GitOps 배포 Blue-Green·Canary로 신버전 트래픽 이동을 단계적으로 제어하고, Helm 차트·Argo 매니페스트를 Git으로 선언적 관리. 헬스체크 실패 시 자동 롤백이 이루어지도록 파이프라인을 구성했습니다.
Planner–Generator–Evaluator 자체 평가 루프 단일 LLM 호출의 "유창하지만 검증 불가" 문제를 해결하기 위해, 질문 분해(Planner) → 응답 생성(Generator) → 응답 검증(Evaluator) 3단계 에이전트 루프를 직접 구현. 응답을 자가 검증하고 실패 시 Self-Correction 경로로 재시도하되, 최대 재시도 3회로 상한을 두어 토큰 비용 폭주를 방지합니다.
성과
  • RAG 전구간(문서 업로드 → 하이브리드 검색 → LLM 라우팅 → SSE 스트리밍) 엔드투엔드 구현
  • 테스트 커버리지 86.37% (Jest 리포트 기준), 주요 경로 통합 테스트 포함
  • 8,192 토큰 컨텍스트 제약에서 greedy packing으로 응답용 2,048 토큰 확보
  • 관측성 스택 함께 구성 — Prometheus · Grafana · Langfuse · OpenTelemetry · Sentry

FireGenerators — AI 투자 추천 RAG 시스템

2025.08 — 2025.09
부트캠프 팀 프로젝트 · RAG 파이프라인 담당
문제
사용자의 투자 성향(보수/공격)은 임베딩 유사도만으로 반영되지 않아, 의미 유사도 기반 검색만으로는 적합도가 떨어진 추천이 섞여 들어왔습니다. 동시에 로컬 실험과 프로덕션 전환 단계에서 벡터 스토어를 다르게 쓰면 코드 분기가 늘어나 실험 속도가 느려졌습니다.
해결
Pinecone + FAISS 이중화 (인터페이스 통일) 개발에는 FAISS로 로컬에서 빠르게 실험하고 프로덕션에서는 Pinecone으로 전환하되, 인터페이스를 동일하게 유지해 코드 수정 없이 전환 가능하도록 구성했습니다.
임베딩 검색 후 GPT-4o 리랭킹 상위 N개 후보를 GPT-4o로 재정렬해 의미 관련도와 투자 성향 조건 적합도를 함께 반영했습니다.
성과
  • RAG 플로우(투자 성향 → 임베딩 → Pinecone 검색 → GPT-4o 리랭킹 → 추천) 설계·구현 주도
  • 100여 개 프롬프트 조합 비교 실험으로 응답 관련성·일관성 개선
  • Supabase 사용자 관리 + yfinance 실시간 시세 연동

자동매매 시리즈 — 주식 & 암호화폐

2025.12 — 2026.03
개인 프로젝트 · 비용·안정성 최적화 중심
문제
KIS Open API·거래소 API는 호출 한도·과금이 있어, 수백 종목을 주기적으로 감시하는 구조에서는 비용과 응답 지연이 동시에 증가합니다. 또한 텔레그램·외부 지표 같은 부가 API가 실패하면 주 거래 로직까지 함께 중단될 위험이 있어, 부가 경로와 주 경로를 분리할 필요가 있었습니다.
해결
TTL 다층 캐싱 + 조회 경로 배치화 (주식) 동일 데이터 재호출을 캐시 계층에서 제거하고, 종목별 개별 호출을 배치로 묶어 라운드트립을 줄였습니다.
Fail-open 설계 + 거래소 인터페이스 추상화 (암호화폐) 부가 API 실패는 경고만 남기고 주 거래 로직은 이어가도록 경로를 분리했습니다. 거래소 연동은 ABC 기반 인터페이스로 추상화해 업비트·바이낸스를 코드 수정 없이 교체할 수 있도록 했습니다. 5단계 신호 필터 체인으로 오진입을 방지합니다.
